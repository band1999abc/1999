6. 不要なスクロール・画面枠について、要件を少し変更して実装してください。

今回の目的は「スクロールを禁止すること」ではありません。

【基本方針】

コンテンツ量と実際の表示領域に応じて、
ページが柔軟に「スクロール不要 / スクロール必要」を切り替えられる設計にしてください。

つまり、

- コンテンツが表示領域内に収まる場合
  → 不要な縦スクロールを発生させない
- コンテンツが表示領域を超える場合
  → 自然に縦スクロールできる
- コンテンツが将来的に増えた場合
  → CSSやJSを変更しなくても自動的にスクロール可能になる
- PC / iPad / iPhoneなど、表示領域が異なる端末
  → 同じページでも必要に応じてスクロールの有無が変わる
- SafariのブラウザUIによって実際のviewport高さが変化する場合
  → 固定値によって表示領域を無理に固定しない

【重要】

「現在このページは短いからoverflow:hiddenにする」
「bodyのスクロールを常に禁止する」
のようなページ単位の固定的な制御は避けてください。

将来コンテンツが増えたときにスクロールできなくなる実装は禁止です。

また、全ページに一律で
overflow-x:hidden / overflow-y:hidden
などを追加するのも避けてください。

まず既存コードを調査し、

- html
- body
- 各ページのmain/container
- style.css
- admin.css
- live.js
- diary.js
- music.js
- track.js
- whale.js
- Flyerモーダル
- After Hoursのモーダル

などについて、
現在のスクロールやviewport高さに関係するCSS/JSを洗い出してください。

【実装方針】

基本的には通常のドキュメントフローを維持してください。

ページの最小高さをviewportに合わせる必要がある場合も、
固定的なheightではなく、端末の実際の表示領域を考慮した柔軟な方法を使用してください。

特にiOS Safariではvhの扱いに注意し、
必要に応じてdvh/svhなどを検討してください。

ただし、単純に全体を100dvh固定するなど、
コンテンツが増えたときに切れてしまう設計にはしないでください。

【横スクロール】

意図しない1〜数px程度の横スクロールについては原因を特定して修正してください。

ただし、原因を特定せず全体にoverflow-x:hiddenを追加して隠すだけの対応は禁止です。

【クジラ】

クジラのサイズ、速度、アニメーション、デザインは変更しないでください。

現在のクジラ位置調整も維持してください。

ただしviewportサイズが変わったときに位置計算が破綻している場合は、
既存デザインを維持したまま必要最小限の再計算処理を検討してください。

【Flyerモーダル】

背景ページのスクロール制御は維持してください。

ただし、モーダル自体のコンテンツが端末の表示領域を超える場合は、
モーダル内部で自然にスクロールできるようにしてください。

【After Hours】

管理画面も同様に、

- 内容が少ない → 不要なページスクロールをできるだけ発生させない
- 内容が多い → 自然にスクロールできる
- モーダルやチャットなど、意図的にスクロールする領域は維持

という考え方にしてください。

【最重要】

今回のゴールは、

「スクロールをなくす」

ではなく、

「不要なスクロールは発生させず、必要なスクロールはコンテンツ量・端末・viewportに応じて自然に発生する」

ことです。

将来DiaryやLiveなどのコンテンツが増えても、
追加のCSS修正なしで正常に閲覧できる設計を優先してください。

まず実装前に現在の問題箇所と修正方針を整理してください。

その後、安全に実装できる場合はPreview用に実装してください。

今回の作業では、

- Analytics
- Music
- Diary / Liveのページネーション
- Node.js
- Blob
- Redis
- CMS
- 環境変数

には変更を加えないでください。

GitHub Push・Production Deploymentもまだ行わないでください。

実装後は、

1. 変更したファイル
2. 不要なスクロールが発生していた原因
3. どのように柔軟なスクロールへ変更したか
4. コンテンツが増えた場合の挙動
5. PC / iPad / iPhoneで想定される挙動
6. 横スクロール対策
7. モーダルのスクロール
8. 既存デザインへの影響

を報告してください。
